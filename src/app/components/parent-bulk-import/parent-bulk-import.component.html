How this works
  • One row per parent-student relationship — a parent with three children on file is three rows sharing the same name, phone and email.
  • Parent IDs are generated for you. Each new parent is emailed a secure link to set their own password — you never type one.
  • A parent who already exists (matching phone and email) is never duplicated; only the new relationship is added.
  • A row matching on phone or email but not both is flagged for your review — never merged automatically.
  • The pre-fill sheet is built from the Father/Mother names already on file; phone and email are left blank for you to complete.
